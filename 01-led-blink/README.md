# 01 — LED Blink

## Objective

Write a simple Arduino program that makes an LED turn on and
off repeatedly at constant intervals.

## Components

- Arduino Uno R3
- LED
- 220 ohm resistor
- Breadboard
- Jumper wires

## What I learned

- The structure of an Arduino program (`setup()` and `loop()`)
- How to configure a digital pin with `pinMode()`
- How to control a digital output with `digitalWrite()`
- The difference between `HIGH` and `LOW`
- How `delay()` affects program timing

## Code

See `blink.ino`.

## Result

The LED turns on for half a second and then off for half a second,
repeating continuously.
